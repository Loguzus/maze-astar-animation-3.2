## Описание проекта
Интерактивное графическое приложение на языке Python (	kinter) для процедурной генерации лабиринтов и пошаговой визуализации алгоритмов поиска кратчайшего пути на сетке (**A*** и **BFS**).

## Функциональные возможности
### Основной функционал
- 🧱 Пошаговая анимированная генерация лабиринтов через поиск в ширину
- 🧭 Визуализация алгоритма поиска кратчайшего пути **A*** с манхэттенской эвристикой
- 🎨 Цветовая индикация посещенных, текущих клеток и кратчайшего пути

### Дополнительный функционал
- 🔄 Второй алгоритм поиска пути — **BFS (поиск в ширину)**
- 📐 Изменение размеров лабиринта (15x15, 25x25, 35x35)
- 💾 Экспорт и импорт лабиринтов во внешний JSON-файл
- 🖱️ Рисование и удаление стен кликом мыши

## Требования к системе
- **Python:** 3.9 или выше
- **ОС:** Windows / macOS / Linux
- **Библиотеки:** 	kinter, heapq, collections, json, unittest (стандартная библиотека)

## Установка и запуск
### 1. Клонирование репозитория
`ash
git clone [https://github.com/Loguzus/maze-astar-animation-3.2.git](https://github.com/Loguzus/maze-astar-animation-3.2.git)
cd maze-astar-animation-3.2
`
### 2. Создание и активация виртуального окружения
`ash
py -m venv venv
venv\Scripts\activate
`
### 3. Установка зависимостей
`ash
pip install -r requirements.txt
`
### 4. Запуск программы
`ash
py main.py
`
### 5. Управление
- **Кнопки панели** — генерация лабиринта, запуск A* и BFS, смена размера, экспорт/импорт
- **ЛКМ по клетке** — поставить или убрать стену
