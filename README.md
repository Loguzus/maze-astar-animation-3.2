## Описание проекта
Интерактивное графическое приложение на языке Python (tkinter) для процедурной генерации лабиринтов и пошаговой визуализации алгоритмов поиска кратчайшего пути на сетке (A* и поиск в ширину BFS). Поддерживается выбор размерности лабиринта, ручное редактирование стен мышью, а также экспорт и импорт лабиринтов во внешний JSON-файл.

## Функциональные возможности
- Пошаговая анимированная генерация лабиринтов через рандомизированный обход
- Визуализация алгоритма поиска кратчайшего пути A* с манхэттенской эвристикой
- Цветовая индикация: стены, посещенные клетки, фронт поиска, текущая вершина и итоговый путь
- Реализация второго алгоритма поиска пути — BFS (поиск в ширину) для сравнения с A*
- Изменение размеров сетки лабиринта в один клик (15x15, 25x25, 35x35)
- Экспорт сгенерированного лабиринта во внешний JSON-файл и импорт из файла
- Интерактивное рисование и удаление стен кликом левой кнопки мыши

## Установка и запуск
1. Клонирование: `git clone [https://github.com/Loguzus/maze-astar-animation-3.2.git](https://github.com/Loguzus/maze-astar-animation-3.2.git)`
2. Создание окружения: `py -m venv venv`
3. Активация: `venv\Scripts\activate`
4. Запуск программы: `py main.py`
5. Запуск тестов: `py -m unittest discover -s tests`
